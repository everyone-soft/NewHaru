# NewHaru GitHub Pages

This directory contains the website files for NewHaru app that can be hosted on GitHub Pages.

## Files Included

- `index.html` - Main landing page for the app
- `privacy-policy.html` - Privacy policy page required for App Store submission
- `styles.css` - Stylesheet for the website

## How to Use with GitHub Pages

1. Create a GitHub repository for NewHaru (if you haven't already)
2. Push this `docs` folder to the repository
3. Go to your repository settings on GitHub
4. Scroll down to the "GitHub Pages" section
5. Select "main branch /docs folder" as the source
6. Click Save

GitHub will provide you with a URL for your site (typically in the format `https://yourusername.github.io/repository-name/`).

## URLs for App Store Submission

Once your GitHub Pages site is live, you can use these URLs for your App Store submission:

- Privacy Policy URL: `https://yourusername.github.io/repository-name/privacy-policy.html`

## Customization

Feel free to customize the HTML and CSS files to match your branding. You can also add:

- Actual screenshots of your app (replace placeholder-screenshot.png references)
- Your App Store link once the app is published
- Additional pages as needed
